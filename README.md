# Blinkit Sales Analysis Dashboard

## Project Overview

This project is a Power BI dashboard created to analyze Blinkit's sales data and understand key business performance metrics.

The dashboard provides an interactive view of sales performance based on product categories, outlet types, outlet sizes, location types, and other important factors.

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization

## Dashboard Insights

The dashboard includes analysis of:

- Total Sales
- Average Sales
- Number of Items
- Average Rating
- Sales by Item Type
- Sales by Outlet Type
- Sales by Outlet Size
- Sales by Outlet Location
- Sales by Fat Content
- Outlet Establishment Trends
